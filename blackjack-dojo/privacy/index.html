プライバシーポリシー

制定日：2026年11月17日

このプライバシーポリシーは、JinenLab（以下「運営者」）が提供する iPhone アプリ「ブラックジャック道場」（英語名「Hit or Stand?」。以下「本アプリ」）で、利用者の情報をどのように扱うかを説明するものです。

1. 運営者が取得する情報

本アプリには、アカウントの登録やログインはありません。運営者が、氏名・メールアドレス・電話番号などの個人を特定できる情報を、本アプリを通じて取得することはありません。運営者のサーバーに、利用者の情報を送ることもありません。

お問い合わせをいただいた場合に限り、返信のために、いただいたメールアドレスと内容を使います。

2. 端末の中だけに保存する情報

本アプリは、次の情報を利用者の端末の中だけに保存します。これらの情報は、運営者や第三者には送りません。

  • プレイ履歴（各ハンドでの判断と、その正誤の記録）
  • ゲームのルールの設定
  • エネルギーの状態
  • その日に広告を視聴した回数
  • 広告に関する同意の選択（「4. 同意の管理」を参照）

端末のバックアップ（iCloud バックアップなど）の設定によっては、これらの情報がバックアップに含まれることがあります。

3. 広告（Google AdMob）

本アプリは、エネルギーを回復するための動画広告（リワード広告）を表示するために、Google LLC が提供する広告サービス「Google AdMob」（Google Mobile Ads SDK）を使っています。広告は、利用者が自分で視聴を選んだときだけ表示します。

広告の配信・効果の測定・不正の防止などのために、Google は次のような情報を取得することがあります。

  • IP アドレス（おおよその位置の推定に使われることがあります）
  • 端末の機種・OS のバージョン・言語などの端末の情報
  • アプリごとの端末の識別子（ベンダー ID〔IDFV〕）
  • 広告の表示・タップなどの操作の情報
  • アプリの動作に関する診断の情報

本アプリは、トラッキングの許可（App Tracking Transparency）を求めません。そのため、本アプリから広告識別子（IDFA）が Google に渡されることはありません。

Google による情報の取り扱いについては、次のページをご覧ください。

  • Google プライバシーポリシー
  • Google のサービスを使用するサイトやアプリから収集した情報の Google による使用
  • 広告に関するポリシー（Google）

4. 同意の管理

欧州経済領域（EEA）・英国・スイスと、プライバシーに関する法律がある米国の州では、Google の同意管理ツール「User Messaging Platform」を使い、広告でのデータの使い方についての同意の画面を表示します。同意の画面の表示が必要かどうかを判断するため、本アプリは起動時に Google と通信します。

これらの地域では、本アプリの「設定」の「プライバシー」にある「プライバシーの設定」から、いつでも選択を変えられます。同意しない場合でも、本アプリのゲームと学習の機能はそのまま使えます（広告によるエネルギーの回復は、使えないことがあります）。

米国の一部の州の居住者は、州法に基づき、ターゲティング広告のための個人情報の「販売」や「共有」をやめるよう求める権利などを持つ場合があります。この選択も「プライバシーの設定」から行えます。運営者自身が、利用者の個人情報を販売することはありません。

5. アップデートの確認

本アプリは、新しいバージョンをお知らせするため、起動時に GitHub Pages（GitHub, Inc. が提供するサービス）から、最新のバージョンを記した設定ファイルを読み込みます。このとき、プレイ履歴などの本アプリの情報は送りません。ただし、通信の際に、IP アドレスなどがアクセスの記録として GitHub に残ることがあります。詳しくは GitHub のプライバシーに関する声明をご覧ください。

6. 情報の削除

  • プレイ履歴は、本アプリの「戦略学習」→「プレイ分析」にある「プレイ履歴を削除」から削除できます。
  • 本アプリを端末から削除すると、端末に保存したすべての情報が削除されます。
  • Google が取得した情報については、Google のプライバシーポリシーに記載された方法で、確認や削除を求められます。

7. 年齢について

本アプリは、18 歳以上の方を対象としています。13 歳未満の子どもから、意図して個人情報を取得することはありません。

8. 実際のお金について

本アプリは、ブラックジャックの戦略を学ぶためのアプリです。本アプリで使うチップやバンクロールは架空のもので、実際のお金を賭けること、賞金を受け取ること、換金することはできません。

9. このポリシーの変更

運営者は、本アプリの機能の変更や法令の変更に合わせて、このポリシーを変更することがあります。変更した場合は、このページで改定日とともにお知らせします。
