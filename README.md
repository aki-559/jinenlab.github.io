# jinenlab.github.io

JinenLab の公開ページ（GitHub Pages）。`https://aki-559.github.io/jinenlab.github.io/` で公開している。

| パス | 内容 |
|---|---|
| `index.html` | トップ（App Store のマーケティング URL） |
| `blackjack-dojo/privacy/`・`privacy/en/` | ブラックジャック道場（Hit or Stand?）のプライバシーポリシー |
| `blackjack-dojo/support/`・`support/en/` | サポート・お問い合わせ |
| `blackjack-dojo/app-config*.json` | アップデートの案内の設定（アプリが読み込む） |
| `assets/style.css` | ページの共通スタイル |

アプリのデータの扱いを変えたとき（SDK の追加など）は、プライバシーポリシーも更新する。
